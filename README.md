## 🎯 Project Overview

This project focuses on identifying meaningful customer segments based on purchasing behavior using **RFM (Recency, Frequency, Monetary) Analysis** and **K-Means Clustering**.

The objective is to help businesses understand customer behavior, improve retention strategies, optimize marketing campaigns, and increase revenue through data-driven decision-making.

---

## 🚀 Business Objectives

- Analyze customer purchasing behavior.
- Calculate RFM metrics for each customer.
- Identify high-value customers.
- Detect customers at risk of churn.
- Create meaningful customer segments.
- Generate actionable business insights.
- Support targeted marketing campaigns.

## 🔄 Project Workflow

### 📥 1. Data Collection

Collected customer transaction data containing:

- Customer Information
- Purchase History
- Order Details
- Revenue Data

---

### 🧹 2. Data Cleaning

Performed preprocessing steps:

- Removed Duplicate Records
- Handled Missing Values
- Corrected Data Types
- Standardized Data Formats
- Prepared Dataset for Analysis

---

### 📊 3. RFM Analysis

Calculated key customer metrics:

| Metric | Description |
|----------|-------------|
| Recency | Days since last purchase |
| Frequency | Number of purchases |
| Monetary | Total amount spent |

These metrics help evaluate customer engagement and value.

---

### 🤖 4. Customer Segmentation

Applied **K-Means Clustering** to group customers into distinct segments based on RFM scores.

Customer groups identified:

- 🏆 Champions
- 💎 Loyal Customers
- 🌟 Potential Loyalists
- ⚠️ At Risk Customers
- ❌ Lost Customers

---

### 📈 5. Model Evaluation

Determined optimal cluster count using:

- Elbow Method
- Silhouette Score Analysis

This ensured effective customer segmentation.

---

### 📊 6. Dashboard Development

Built an interactive Power BI dashboard for business stakeholders.

Dashboard includes:

- Customer Segments
- Revenue Analysis
- Product Performance
- Business Insights
- Customer Retention Metrics
